Title: Sleep Apnea Detection from single-lead ECG: A comprehensive analysis 
of machine learning and deep learning algorithms 
Abstract: 
This project proposes a comprehensive study of machine learning and deep 
learning techniques for detecting sleep apnea using single-lead ECG signals. 
Traditional sleep apnea diagnosis requires costly overnight polysomnography, 
making early detection difficult for many patients. Using ECG-derived 
respiratory features, the system extracts key biomarkers such as RR interval 
variability, waveform morphology, and apnea-related arrhythmia patterns. A 
wide range of ML models including SVM, Random Forest, Gradient Boosting 
and DL models like 1D-CNN, LSTM, and hybrid CNN-LSTM architectures 
were evaluated. The dataset contains annotated ECG recordings with apnea and 
non-apnea episodes. Signal preprocessing techniques like noise filtering, 
segmentation, and feature normalization significantly improve model stability. 
The study highlights how deep learning models automatically learn temporal 
dependencies linked to breathing irregularities. Experimental comparison shows 
that CNN-LSTM hybrid networks achieve the highest performance, effectively 
capturing both spatial signal patterns and long-term temporal variations. The 
project also includes subject-wise cross-validation to ensure generalization. 
Overall, this work establishes a low-cost, non-invasive, and accurate method for 
early sleep apnea screening using a single ECG channel.
